# 参数说明

27 项参数，五组。两个平台的键名、范围、步长、默认值完全一致，
配置文件（`settings.ini`）可以互相搬。

> 打开方式：Windows —— 左键点托盘图标；Android —— 点桌面图标进设置页。
> 所有改动**立即生效并自动保存**，不需要重启。

---

## 一分钟版：只调这三个

| 想要的效果 | 调哪个 | 怎么调 |
|---|---|---|
| 光柱太矮 / 不跟节奏跳 | **音频响应强度** | 1.0 → 1.5~2.5 |
| 想让柱子「实」一点，更像灯管 | **光柱实心度** | 0.10 → 0.4~0.8 |
| 柱子太宽 / 想让它更贴边 | **光柱离边距离** | 负值往外推，正值往中间挪 |

其余参数**默认值就是原作品的调校结果**，不动也能用。

## 一、音频响应校准

这一组决定「什么算响」。它是整条链路上最容易调坏的一段 ——
因为它的输出（8 段包络）会被后面所有东西放大。

| 参数 | 键名 | 范围 | 默认 | 作用 |
|---|---|---|---|---|
| 增益 | `gainDb` | −12 ~ +12 dB | 0 | 进 FFT 之前的整体增益。录音太小声就加。 |
| 动态范围 | `widthDb` | 15 ~ 60 dB | 46 | 归一化窗口有多宽。窄 = 更敏感但容易顶满；宽 = 更克制。 |
| 频谱平衡 | `balance` | 0 ~ 100% | 85% | 低频与高频的权重配比。往 100% 走低频占比更大。 |
| 电平映射 | `mapMode` | 每段自适应 / 共用窗口 | 每段自适应 | 见下。 |
| 频率轴 | `bandMode` | 等宽 0–16k / 等比 30–16k | 等宽 | 见下。 |
| 总电平 | `level` | 0.05 ~ 1.00 | 0.15 | 归一化后的总输出电平。**顶满就调低它。** |
| 对比度 | `contrast` | 1.0 ~ 3.0× | 1.8 | 曲线陡不陡。越大，弱信号越被压、强信号越突出。 |
| 常态分位 | `loPct` | 2% ~ 50% | 20% | 滚动直方图里取哪个分位当「0」。 |
| 峰值分位 | `hiPct` | 80% ~ 100% | 99% | 取哪个分位当「1」。 |
| 跟踪窗口 | `rpWinSec` | 3 ~ 30 秒 | 10 | 直方图的时间窗。短 = 跟得快但会「忘」；长 = 稳定但适应慢。 |

### 电平映射：两种模式

- **每段自适应**（默认）—— 8 个频段各自维护一套分位区间。
  好处是弱的高频段也能推出满幅；坏处是「安静时高频噪声也会被放大成满幅」。
- **共用窗口** —— 8 个频段共用一套区间，保持它们之间真实的能量比例。
  鼓点会明显压过低频，但整体更「真实」。

### 频率轴：两种划分

- **等宽 0–16k** —— 每个频段宽度相同（2 kHz）。低频段只有 1 段，
  鼓点全靠 `subBass` 一个值撑，细节少。
- **等比 30–16k** —— 按倍频程划分，低频段更细。**鼓点更准**，
  但高频段会很宽、反应偏钝。

> 这两项在 C++ 版曾经出过一个 bug：不管选哪个观感都一样。
> 原因是频率轴只影响了「频段边界」却没影响「FFT bin 的取法」。见 [移植笔记](移植笔记.md)。

### 校准流程（照这个顺序，别跳）

1. 放一首你**最常听**的歌，正常音量。
2. 看光柱：**一直顶到满幅** → 调低「总电平」；**几乎不动** → 调高「音频响应强度」。
3. 鼓点**不够跳** → 加大「对比度」（1.8 → 2.4）。
4. 慢歌有反应、快歌糊成一团 → 把「跟踪窗口」调短（10 → 5 秒）。
5. 换一首歌再验一遍。**一项一项调，一次只动一个。**

## 二、外观

| 参数 | 键名 | 范围 | 默认 | 作用 |
|---|---|---|---|---|
| 光柱风格 | `styleMode` | 跳动 / 常驻闪色 | 跳动 | 见 [README 的风格对比](../README.md#两种光柱风格)。 |
| 颜色主题 | `themeIndex` | 自动轮询 + 15 套 | 霁紫 | 下拉第 0 项是「自动轮询」，1~15 对应 15 套主题。 |
| 轮询间隔 | `themeCycleSec` | 10 ~ 300 秒 | 60 | 「自动轮询」下多久换一套。 |
| 光柱离边距离 | `beamInset` | −0.15 ~ +0.30 | 0 | 轴心位置。0 = 轴心压在屏幕边上。 |
| 光柱实心度 | `alphaK` | 0 ~ 1 | 0.10 | 0 = 纯加光；1 = 柱心实心会遮挡桌面。 |

### 光柱离边距离怎么理解

它不是「离边留白」，而是**把轴心往画面里挪**：

```
轴心 = 屏幕边缘 + beamInset × 屏宽
```

- `-0.15`（最低）→ 轴心推到屏幕外，柱子**完全离场**（看不见）。
- `0`（默认）→ 轴心正好在屏幕边上，柱身有一半在屏幕内。
- `+0.25` → 两根柱子明显向中间靠拢，射程接近屏宽一半。

⚠ **窄屏（竖屏手机）上这个值会被自动收窄。** 因为横向射程是按「画面高」
归一化的常数，竖屏下换算成屏宽会大得多 —— 不补偿的话，拉到最低柱子也不会消失。
补偿之后，`-0.15` 在任何纵横比下都保证离场。细节见
[移植笔记 · 光柱离边距离为什么在竖屏上不一样](移植笔记.md#beam-inset-aspect)。

### 光柱实心度（alphaK）

这一项决定「光」和「不透明图层」的边界：

| 值 | 合成结果 | 观感 |
|---|---|---|
| 0.00 | 光 + 桌面 | 纯加光。柱心透明，只往上加亮。最像真光。 |
| 0.10 | 光 + 桌面 × 0.9 | 默认。桌面被压暗 10%，几乎看不出。 |
| 0.50 | 光 + 桌面 × 0.5 | 柱子开始有「实体感」，桌面明显变暗。 |
| 1.00 | 光 + 桌面 × 0 | 柱子完全不透明，遮挡桌面。 |

## 三、音频响应

| 参数 | 键名 | 范围 | 默认 | 作用 |
|---|---|---|---|---|
| 音频响应强度 | `audioIntensity` | 0.3 ~ 2.5 | 1.0 | **主音量**。直接乘在驱动量上。 |
| 响应范围 | `responseRange` | 0.3 ~ 2.0 | 1.0 | 另一级乘法，用来给不同曲子留余量。 |
| 启用强调色 | `peakEnabled` | 开 / 关 | 开 | 关掉后，风格② 闪色退回主题暖色。 |
| 强调色强度 | `peakIntensity` | 0 ~ 2.0 | 1.0 | 闪色的浓度。 |

`audioIntensity` 和 `responseRange` 是**相乘**的（都进 `drive`），
所以它们的效果可以叠加：`1.5 × 1.4 = 2.1`。

> 为什么留两个而不是一个？因为原作品就是这么分的：一个是「作品响度」，
> 一个是「这首曲子的动态余量」。移植时没有合并，保持参数体系一致。

## 四、空闲波浪

没有声音的时候光柱慢慢呼吸。这是原作品的一个细节：
呼吸是**有基数的正弦叠加**（`0.66 + 0.20·sin + 0.14·sin`），
不是两个正弦相乘 —— 相乘的谷底会归零，光柱会周期性整个消失。

| 参数 | 键名 | 范围 | 默认 | 作用 |
|---|---|---|---|---|
| 启用空闲波浪 | `idleEnabled` | 开 / 关 | 开 | 总开关。 |
| 防抖 | `idleDebounce` | 0.5 ~ 5 秒 | 1.0 | 安静多久之后才进入呼吸状态。 |
| 过渡 | `idleFade` | 0.5 ~ 5 秒 | 1.0 | 从「跟着音乐」淡出到「自己呼吸」用多久。 |

> 听播客 / 开会时建议把「防抖」调到 3 秒以上，否则句间停顿会让柱子一跳一跳。

## 五、性能

| 参数 | 键名 | 可选值 | 默认 | 作用 |
|---|---|---|---|---|
| 渲染帧率 | `fpsLimit` | 30 / 60 / 120 / 144 | 60 | 每秒画多少帧。 |
| 音频分析频率 | `anaHz` | 30 / 60 / 120 / 250 | **250** | 每秒算多少次包络。 |

### 这两个不是一回事

```
频谱采集 30 Hz（固定）→ 分析层 = anaHz → 渲染层 = fpsLimit
```

三层各有自己的时钟。设成同一个值**不代表**它们对齐了。

- **`anaHz` 决定包络的「跟随速度」。** 250 是桌面版实测值（那个定时器跑 249.6 次/秒）。
  调到 60 会让包络慢 4.5 倍 —— 表现是「幅度变小、部分节拍不响应」。
  这正是移植时踩过的一个坑：默认值一度写成 60，用户反馈「和 Electron 版比响应弱」。
- **`fpsLimit` 只影响画面顺滑度，不影响幅度。** 30 和 144 的柱子一样高，只是动得更顺。

> 省电场景（笔记本用电池 / 手机）：`fpsLimit = 30`，`anaHz` 保持 250。
> 反过来设（`anaHz = 30`、`fpsLimit = 144`）是最差组合：画面很顺，但跟不上音乐。

## 六、机器项（不属于作品参数）

这几项记的是「你对这台机器的选择」，所以：

- **「恢复默认设置」不会重置它们。**
- 换机器 / 换显示器时需要重设。

| 键名 | 平台 | 说明 |
|---|---|---|
| `displayIndex` | Windows | 画在哪块屏。`-1` = 主屏。 |
| `audioIdleMode` | Windows | 音频设备空闲时怎么办。 |
| `audioSourceIndex` | Android | 0 = 麦克风，1 = 内部音频。 |

## 七、调坏了怎么救

| 症状 | 最可能的原因 | 怎么办 |
|---|---|---|
| 完全看不见光柱 | 驱动量太低（安静的歌 + 强度 1.0） | 先把「音频响应强度」拉到 2.5 试 |
| 一直顶满、不跟着跳 | 「总电平」太高 | 调到 0.05~0.10 |
| 鼓点没反应 | 频率轴选了「等宽」，或「跟踪窗口」太长 | 换「等比 30–16k」，窗口调到 5 秒 |
| 柱子闪得晃眼 | 「对比度」太高 + 「强调色强度」高 | 对比度回 1.8，强调色关掉 |
| 柱子完全消失，怎么调都没用 | `beamInset` 在最低位 | 调到 0 |
| 桌面被压暗得太厉害 | `alphaK` 太高 | 回到 0.10 |
| 改了没反应 | 配置被别处覆盖（旧版残留 / 权限） | 「恢复默认设置」，再逐项调 |

**万能兜底**：面板里点「恢复默认设置」。它只重置参数，
**不动保存过的预设**，也**不动上面第六节那几个机器项** —— 所以可以放心点。
